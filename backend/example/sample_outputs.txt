Example 1 — Simple MLP Classifier
--------------------------------------------------------------------------------

INPUT PIPELINE (condensed):
  dataset → linear(784→256) → relu → linear(256→128) → relu → linear(128→10) → softmax → output

GENERATED CODE:
  import torch
  import torch.nn as nn

  model = nn.Sequential(
      nn.Linear(784, 256),
      nn.ReLU(),
      nn.Linear(256, 128),
      nn.ReLU(),
      nn.Linear(128, 10),
      nn.Softmax(dim=1),
  )

  x = torch.tensor(input_data, dtype=torch.float32)   # shape [N, 784]

  model.eval()
  with torch.no_grad():
      output = model(x)   # shape [N, 10]  — class probabilities

--------------------------------------------------------------------------------
Example 4 — Deep Classifier with BatchNorm and Dropout
--------------------------------------------------------------------------------

INPUT PIPELINE (condensed):
  dataset → linear(512→256) → batchnorm1d(256) → relu → dropout(0.4)
          → linear(256→128) → batchnorm1d(128) → relu → dropout(0.4)
          → linear(128→10)  → logsoftmax → output

GENERATED CODE:
  import torch
  import torch.nn as nn

  model = nn.Sequential(
      nn.Linear(512, 256),
      nn.BatchNorm1d(256),
      nn.ReLU(),
      nn.Dropout(p=0.4),
      nn.Linear(256, 128),
      nn.BatchNorm1d(128),
      nn.ReLU(),
      nn.Dropout(p=0.4),
      nn.Linear(128, 10),
      nn.LogSoftmax(dim=1),
  )

  x = torch.tensor(input_data, dtype=torch.float32)   # shape [N, 512]

  model.eval()
  with torch.no_grad():
      output = model(x)   # shape [N, 10]  — log-probabilities (use with NLLLoss)

INPUT PIPELINE (condensed):

  model.eval()
  with torch.no_grad():

--------------------------------------------------------------------------------
Example 6 — Embedding + Classifier
--------------------------------------------------------------------------------

INPUT PIPELINE (condensed):
  dataset → embedding(30522, 128) → flatten(start_dim=1) → linear(768→64) → relu → linear(64→2) → softmax → output

GENERATED CODE:
  import torch
  import torch.nn as nn

  model = nn.Sequential(
      nn.Embedding(num_embeddings=30522, embedding_dim=128),
      nn.Flatten(start_dim=1),
      nn.Linear(768, 64),
      nn.ReLU(),
      nn.Linear(64, 2),
      nn.Softmax(dim=1),
  )

  x = torch.tensor(input_data, dtype=torch.long)      # shape [N, seq_len]  — integer token IDs

  model.eval()
  with torch.no_grad():
      output = model(x)   # shape [N, 2]  — sentiment probabilities


================================================================================
HOW build_model() PRODUCES THIS
================================================================================

For every node in the pipeline JSON:
  1. Skip "dataset" and "output" (CONTROL_NODES)
  2. Look up node["type"] in LAYER_REGISTRY to get the nn.Module class
  3. Pass remaining keys as **kwargs to the constructor
  4. Append to a list of layers
  5. Wrap in nn.Sequential(*layers)

Then run_pipeline() extracts the data array from the "dataset" node,
converts it to a torch.Tensor, and calls model(x) to produce the output.
